Frequently Asked Questions

Which links can I extract?

Only public ChatGPT shared links beginning with https://chatgpt.com/share/ or the legacy chat.openai.com/share/ format.

Do I need to sign in?

No ChatVault account or ChatGPT login is requested. The shared page must be publicly accessible to the browser service.

Are images and file attachments included?

This version extracts message text. Images, uploaded files, and other binary attachments are not included in the text exports.

Why can an extraction fail?

A link may be private, deleted, unavailable, or blocked by the source platform. ChatGPT can also change its shared-page structure, which may require an extractor update.

Does ChatVault save my conversations?

No conversation archive or database is used. The extraction service processes the public link for the request and returns the result to your browser.
